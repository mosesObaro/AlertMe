## 6. Recent Publications
### Efficient Memory Management for Large Language Model Serving with PagedAttention (2023)
* **Authors:** W. Kwon, Z. Li, S. Zhuang, Y. Sheng, L. Zheng, C. H. Yu, J. E. Gonzalez, H. Zhang, I. Stoica
* **Venue:** ACM SOSP
* **Reference / DOI:** [https://doi.org/10.1145/3600006.3613165](https://doi.org/10.1145/3600006.3613165)
* **Research Problem:** Severe DRAM memory fragmentation in KV cache limits concurrent throughput during model serving.
* **Approach / Methodology:** Virtual memory paging applied to transformer attention key-value caches.
* **Key Contribution:** Increases serving throughput by 2-4x without altering model accuracy.
* **Edge Computing Relevance:** Crucial technique for deploying large models on resource-constrained edge memory.
