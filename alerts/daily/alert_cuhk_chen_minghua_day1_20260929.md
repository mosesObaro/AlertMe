Paper: Markov Approximation for Combinatorial Network Optimization

Year: 2013
Link: https://doi.org/10.1109/tit.2013.2268923

RESEARCH PROBLEM:
Many network design problems are combinatorial and hard to solve with distributed algorithms.

APPROACH:
Markov approximation: approximating the optimum with a log-sum-exp function whose solution is the stationary distribution of time-reversible Markov chains that can be run distributedly.

KEY CONTRIBUTION:
A general framework for designing distributed algorithms with provable performance, illustrated through three network applications.
